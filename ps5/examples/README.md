# Examples

One folder per real input your workflow has run on, such as `examples/acme-intern/`, holding the
input as `input.<ext>` and what the workflow produced from it as `output.<ext>`. You need at
least ten. Commit each one when you run it, so the record shows the workflow running over the
course of the work. If an input has someone's personal details in it, replace them with made-up
ones first.
